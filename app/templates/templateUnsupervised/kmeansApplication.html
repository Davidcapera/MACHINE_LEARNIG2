K-Means Application — Customer Segmentation

Dynamic clustering application using K-Means over customer age and income.

1 · Problem Description

This clustering application predicts customer behavior using age and income. K-Means automatically assigns users to one of three customer groups using unsupervised machine learning.

Objective

Identify customer purchasing profiles through cluster segmentation.

Algorithm
K-Means Unsupervised Learning Customer Clustering
2 · Dataset Context

This dataset represents synthetic customer profiles created for clustering analysis. Each record contains customer characteristics used for segmentation.

Feature 1

Age between 20 and 65 years old.

Feature 2

Monthly income between $1,000 and $8,000.

4 · Data Preparation
Step 1: Dataset generated using make_blobs().
Step 2: Features scaled into realistic age and income ranges.
Step 3: K-Means model trained using sklearn.cluster.KMeans.
Step 4: Dynamic prediction generated from user input.
5 · How To Use This Application
  1. Enter customer age.
  2. Enter monthly income.
  3. Click Analyze Customer.
  4. Review assigned cluster.
  5. Interpret graph and centroids.
This application helps identify customer segments for marketing analysis and business decision-making.
