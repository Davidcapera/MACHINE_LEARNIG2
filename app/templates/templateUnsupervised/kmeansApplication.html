About This Application

This interactive K-Means application allows users to simulate customer segmentation using Machine Learning.

The algorithm groups customers based on:

  • Age — customer age range
  • Income — monthly income level

By entering values, the system dynamically predicts which cluster the customer belongs to and visualizes the result using a real-time clustering graph.

How to Use
  1. Enter the customer's age.
  2. Enter the customer's monthly income.
  3. Click Analyze Customer.
  4. Review the assigned cluster.
  5. Interpret the graph and centroid positions.
Cluster Interpretation
Budget Customers

Lower income users with basic purchasing behavior.

Standard Customers

Medium income customers with balanced purchasing capacity.

Premium Customers

High-income users likely to engage with premium services.
