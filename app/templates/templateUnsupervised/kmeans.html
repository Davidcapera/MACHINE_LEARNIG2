1 · Problem Description

Title

Customer Segmentation by Age and Income

Problem Description

K-Means is applied to group 100 individuals by their age and monthly income. The algorithm selects 3 initial centroids manually and runs 3 complete iterations: Euclidean distance calculation, cluster assignment, and centroid recalculation. The variance is measured at each iteration to verify convergence.

Type of Machine Learning

Unsupervised Learning Clustering K-Means (k=3)
