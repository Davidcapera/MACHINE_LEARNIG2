Unsupervised Learning — K-Means Clustering

K-Means is a powerful unsupervised learning algorithm used to identify hidden patterns in unlabeled data by grouping similar observations.

Figure 1. Visual representation of clustering.

What is Unsupervised Learning?

Unsupervised learning analyzes data without labeled outputs and discovers hidden structures and patterns. It is widely used when data labeling is not available.

  • No labeled output
  • Pattern discovery
  • Clustering and dimensionality reduction

Figure 2. Example of clustering.

What is Clustering?

Clustering groups data based on similarity, allowing identification of patterns and meaningful segments.

Algorithm Process
  1. Select centroids
  2. Calculate distances
  3. Assign clusters
  4. Update centroids
  5. Repeat until convergence
Distance (Euclidean)

d = √((x₁ - x₂)² + (y₁ - y₂)²)

Variance Reduction

Variance decreases as clusters become more compact, improving clustering quality.

Applications
  • Customer segmentation
  • Market analysis
  • Anomaly detection
  • Recommendation systems
Interpretation

K-Means identifies patterns and supports decision-making by grouping similar data.
