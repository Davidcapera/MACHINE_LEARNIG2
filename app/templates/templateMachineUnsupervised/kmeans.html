Unsupervised Learning — K-Means Clustering

K-Means is a fundamental algorithm used to discover hidden patterns in unlabeled data by grouping similar observations.

What is Unsupervised Learning?

Unsupervised learning is a type of Machine Learning where the algorithm analyzes data without predefined labels. The goal is to discover hidden structures or patterns within the dataset.

  • No labeled output
  • Pattern discovery
  • Used for clustering and dimensionality reduction

What is Clustering?

Clustering is the process of grouping data points into clusters based on similarity. Points within the same cluster are more similar to each other than to those in other clusters.

What is K-Means?

K-Means is a clustering algorithm that partitions data into K groups, where each group is represented by a centroid. The algorithm iteratively assigns data points to the nearest centroid and updates centroid positions until convergence.

Key Elements of K-Means

  • K: Number of clusters
  • Centroids: Center of each cluster
  • Distance: Usually Euclidean distance
  • Iterations: Repeated updates until convergence

K-Means Algorithm Process

  1. Select K initial centroids
  2. Calculate distance from each point to centroids
  3. Assign each point to the nearest centroid
  4. Recalculate centroids (mean of cluster points)
  5. Repeat until centroids stabilize

Distance Metric (Euclidean)

The Euclidean distance is used to measure similarity between points:

d = √((x₁ - x₂)² + (y₁ - y₂)²)

Variance and Convergence

The algorithm aims to minimize variance within clusters. As iterations progress, variance decreases, leading to more compact and stable clusters.

Real-World Applications

  • Customer segmentation
  • Market analysis
  • Image compression
  • Anomaly detection
